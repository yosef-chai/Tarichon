# תאריכון — וידג'ט תאריך עברי לשורת המשימות — גרסה 0.10.1

וידג'ט ל-Windows 10/11 המציג בשורת המשימות, צמוד לתצוגת התאריך/שעה המקורית:

- **שורה עליונה:** יום בשבוע + פרשת השבוע (לדוגמה: `שני, דברים`)
- **שורה תחתונה:** התאריך העברי המלא (לדוגמה: `כ"ח תמוז ה'תשפ"ו`)

בלחיצה שמאלית על הוידג'ט (או דרך תפריט ההקשר) נפתחת חלונית עם **זמני היום
ההלכתיים**, כולל ניווט בין ימים, לוח שנה עברי או לועזי לבחירת תאריך (בכל יום
מוצג גם התאריך המקביל בלוח השני), והתראות על התקרבות זמן.

דרך תפריט ההקשר (או סמל גלגל השיניים בחלונית הזמנים) נפתח **פאנל הגדרות
מלא**, כולל תצוגה חופשית מעל שולחן העבודה.

זהו **חלק 1+2+3** — כל שלושת החלקים המתוכננים בפרוייקט הושלמו. ראו
"מגבלות ידועות" למטה לפרטים על מה שעדיין לא נתמך.

---

## דרישות מערכת

- Windows 10 (מומלץ 1809 ומעלה) או Windows 11
- לבנייה מקוד המקור: [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (חינמי)
- להרצה בלבד (אם תבנו גרסת **self-contained**, ראו למטה): אין צורך ב-.NET מותקן מראש

## בנייה והרצה

1. התקינו את .NET 8 SDK.
2. פתחו את `HebrewTaskbarWidget.sln` ב-Visual Studio 2022 (ומעלה) **או** הריצו משורת הפקודה מתיקיית הפרוייקט:

   ```powershell
   dotnet build -c Release
   ```

   הפעולה בונה **שני** קבצי הרצה: `HebrewTaskbarWidget.exe` (הוידג'ט
   הראשי) ו-`HebrewTaskbarWidgetSettings.exe` (גישה רשמית לפאנל ההגדרות,
   ראו בהמשך) - שני קבצי ה-.csproj (וכל קוד המקור המשותף) יושבים יחד
   באותה תיקייה, `src\HebrewTaskbarWidget.SettingsRecovery\` (ראו "מבנה
   הפרוייקט" למטה).

3. להרצה ישירה של הוידג'ט הראשי:

   ```powershell
   dotnet run --project src\HebrewTaskbarWidget.SettingsRecovery\HebrewTaskbarWidget.csproj
   ```

4. לבניית קובץ הרצה עצמאי (exe יחיד, לא דורש .NET מותקן במחשב היעד):

   ```powershell
   dotnet publish src\HebrewTaskbarWidget.SettingsRecovery\HebrewTaskbarWidget.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
   ```

   קובץ ה-exe שנוצר יופיע בתיקייה `src\HebrewTaskbarWidget.SettingsRecovery\bin\Release\net8.0-windows\win-x64\publish\`.

## מבנה הפרוייקט

מגרסה 0.5.3, שני קבצי ה-.csproj (`HebrewTaskbarWidget.csproj` - הוידג'ט
הראשי, ו-`HebrewTaskbarWidget.SettingsRecovery.csproj` - כלי הגישה
העצמאי להגדרות) יושבים יחד באותה תיקייה פיזית בדיוק,
`src\HebrewTaskbarWidget.SettingsRecovery\`, יחד עם כל קוד המקור
המשותף (Assets, Controls, Interop, Models, Services, VoiceAnnouncements
וכו') - זאת כדי לבטל כפילות תיקיות מיותרת שהייתה קיימת קודם (שתי תיקיות
נפרדות, שכל אחת "הרגישה" כאילו מכילה עותק שלם של האפליקציה). שני
הקבצים עדיין מקומפלים לשני קבצי הרצה נפרדים לגמרי - פרוייקט
`HebrewTaskbarWidget.SettingsRecovery.csproj` מגדיר `ProjectReference`
לפרוייקט הראשי (השני, שיושב לצדו ממש) ומוסיף רק את שני הקבצים הייעודיים
לו (`SettingsRecoveryApp.xaml`/`.xaml.cs`), עם נתיבי `bin`/`obj` נפרדים
כדי לא להתנגש עם הפרוייקט הראשי.

## הרצה אוטומטית עם הפעלת Windows

**הדרך המומלצת:** הפעילו את "הפעלה עם עליית Windows" בעמוד "כללי" בחלון
ההגדרות - זה כל מה שצריך (נרשם אוטומטית
במפתח ה-Run הרגיל של המשתמש הנוכחי, ללא צורך בהרשאות מנהל).

לחלופין (ידני): צרו קיצור דרך לקובץ ה-exe והניחו אותו בתיקייה:
`%AppData%\Microsoft\Windows\Start Menu\Programs\Startup`

## גישה רשמית לפאנל ההגדרות (ללא תלות בוידג'ט עצמו)

לצד `HebrewTaskbarWidget.exe` נבנה גם קובץ הרצה שני, נפרד:
`HebrewTaskbarWidgetSettings.exe` - פותח ישירות את פאנל ההגדרות הרשמי,
ללא הרצת הוידג'ט עצמו. שינויים שנשמרים כאן נכנסים לתוקף מיידית גם אם
הוידג'ט הראשי כבר רץ ברקע. זו דרך גישה רשמית ומלאה, שימושית
בפרט כאשר הוידג'ט הראשי אינו נראה על המסך (למשל אחרי ניתוק צג חיצוני או
שינוי רזולוציה קיצוני) - במקרה כזה, פתיחה מחדש של התוכנה הראשית לא תעזור
(כבר יש מופע רץ ברקע), ופתיחה ישירה של ההגדרות דרך קובץ זה היא הדרך
היחידה לתקן/לאפס את המיקום. אפשר גם ללחוץ שם על "כיבוי ויציאה מוחלטת
מהתוכנה" כדי לסגור לגמרי את הוידג'ט הראשי, גם בלי גישה ללחיצה עליו.

## איך זה עובד (תמצית טכנית)

- **מיקום:** הוידג'ט מאתר את חלון שעון המערכת בשורת המשימות באמצעות Win32 API,
  עם חיפוש **רקורסיבי** בכל עץ החלונות (`EnumChildWindows`) - כדי לאתר את
  `TrayClockWClass` גם כשהוא מקונן עמוק מאחורי מארחי XAML Islands (כפי שקורה
  ב-Windows 11). **ברירת המחדל: מעל שורת המשימות** - הוידג'ט ממוקם באזור
  שולחן העבודה ממש מעל השעון, מיושר לצד שנבחר (ימין כברירת מחדל), באזור
  שלעולם אינו חופף לסמלי המגש הקיימים. מצב חלופי ("בתוך גובה שורת המשימות,
  לצד השעון") זמין בהגדרות למי שרוצה לנסות, אך עלול לחפוף אם אין שטח פנוי
  אמיתי בפריסת שורת המשימות הספציפית (ראו "מגבלות ידועות" למטה). המיקום
  תמיד מהודק לגבולות המסך, ונבדק ומתעדכן כל חצי שנייה כך שהוידג'ט ממשיך
  "לעקוב" גם אם שורת המשימות זזה/שינתה גודל/הופעלה מחדש.
- **הישארות מעל שורת המשימות** (`Services/TaskbarZOrderGuard.cs`): שורת
  המשימות היא גם היא חלון "עליון", ו-Explorer מעלה אותה מעל הוידג'ט בכל
  לחיצה עליה ובכל פתיחה של תוכנה. השומר מקשיב לאירועי המערכת של שינוי סדר
  החלונות והחלפת החלון הפעיל, בודק אם שורת המשימות מעל הוידג'ט, ואם כן מחזיר
  אותו מעליה מיד (`SetWindowPos` + `HWND_TOPMOST`, בלי לגנוב פוקוס) - ואחר כך
  ממשיך לבדוק כל 16 מ"ש במשך שנייה וחצי, וכל 100 מ"ש בשאר הזמן. כל מה שפונה
  ל-Explorer (מדידת מיקום כפתור "^" ב-UI Automation, הסתרת השעון) רץ ברקע או
  בלי להמתין לו, כדי שהוידג'ט לא ייתקע כש-Explorer עסוק.
- **שקיפות:** החלון עצמו שקוף לחלוטין (`AllowsTransparency`), כך שרואים דרכו את
  צבע הרקע האמיתי של שורת המשימות. מוצג רק הטקסט.
- **גופן וצבע:** ברירת המחדל מדמה את השעון של Windows (`Segoe UI Variable`
  ב-Windows 11, `Segoe UI` ב-Windows 10) עם צבע המתעדכן אוטומטית לפי ערכת
  הנושא (בהיר/כהה); שניהם ניתנים גם להתאמה אישית מלאה בפאנל ההגדרות.
- **הלוח העברי:** מחושב באמצעות `System.Globalization.HebrewCalendar` המובנה
  ב-.NET — חישוב מדוייק ואמין לכל תאריך.
- **חגים ומועדים** (`Services/HolidayCalendar.cs`): ימים טובים וחול המועד,
  צומות עם דחייה והקדמה, ראש חודש, חנוכה, פורים ושושן פורים (כולל פורים
  המשולש), שבתות מיוחדות, ערבי חגים, ספירת העומר, שבת מברכים, אסרו חג, ברכת
  החמה, ומועדים שתלויים במנהג ההלכתי (ליל סליחות, תעניות בה"ב ויום כיפור קטן
  באשכנז; סליחות מב' באלול ומימונה בעדות המזרח). הכל לפי לוח ארץ ישראל או חו"ל
  (יום טוב שני של גלויות), אוטומטית לפי המיקום או בבחירה ידנית. ימים לאומיים
  של מדינת ישראל אינם חלק מהלוח.
- **פרשת השבוע** (`Services/ParashaService.cs`): מחושבת לכל שנה, לפי לוח ארץ
  ישראל או חו"ל, לפי כללי שו"ע או"ח תכח (צירוף פרשות, הפרדה ביניהן בין ישראל
  לחו"ל וכו').
- **בדיקות:** `tests/HebrewTaskbarWidget.Tests` משווה את כל המועדים ואת פרשת
  השבוע לכל יום ב-100 שנה (ה'תש"ס-ה'תתר"ס), בארץ ישראל ובחו"ל, מול נתוני
  Hebcal.com. הרצה: `dotnet test`.
- **זמני היום ההלכתיים:** מחושבים ישירות (`AstronomicalCalculator.cs`,
  `ZmanimMethods.cs`, `ZmanimCalendar.cs`) לפי אלגוריתם השמש של NOAA/Meeus,
  בחישוב איטרטיבי לרגע האירוע עצמו, עם שבירה אטמוספרית וחצי קוטר השמש
  (0.833°). שתי שיטות חישוב לבחירה ב"מיקום וזמני היום":
  - **לוח אור החיים** (ברירת המחדל; ישיבת אור החיים, לפי הוראות הרב עובדיה יוסף): הכל
    בדקות זמניות של היום מהנץ עד השקיעה מהגובה. עלות השחר 72, טלית ותפילין
    66, צאת הכוכבים 13.5, רבנו תם 72; פלג המנחה לפי ילקוט יוסף; מנחה גדולה
    לא לפני חצי שעה אחרי חצות; הדלקת נרות 20 דקות (בירושלים 40) וצאת שבת
    30 דקות.
  - **לוח עתים לבינה** (הרב דניאל גלויברמן): עלות השחר ויום המג"א לפי 90
    דקות במעלות (19.8°; בחו"ל 72 - 16.05°), טלית ותפילין 11.5°, שעות זמניות
    וחצות מהנץ והשקיעה במישור, צאת הכוכבים 18 דקות במעלות (4.66°), צאת שבת
    8.5°, רבנו תם 72 דקות. השקיעה (במישור או מהגובה), הדלקת הנרות וצאת השבת
    לפי מנהג כל עיר בלוח.

  ההגדרות של שני הלוחות נלקחו מהלוחות עצמם (maor.orhachaim.org,
  itimlabina.co.il) ומהקוד של אפליקציית "זמני יוסף" שמשחזרת את לוח אור
  החיים, והבדיקות (`ZmanimMethodsTests`) משוות אותן לזמנים שפורסמו בירושלים
  ובתל אביב. נוספו גם זמן טלית ותפילין וצאת השבת והחג (במוצאי שבת וחג).
  סוף זמן אכילת ושריפת חמץ מופיעים מעצמם בערב פסח, ורבנו תם במוצאי שבת וחג
  יחד עם צאת השבת - בלי הגדרה נפרדת. כל זמן מעוגל לדקה לחומרא, כמו בלוחות
  (אפשר לכבות). ניתן לדרוס את שיטת החישוב, לשנות שם תצוגה ולהוסיף "שורת זמן
  כפולה" בלוח השני, לכל זמן בנפרד, בלחיצה על שם הזמן ברשימת "אילו זמנים
  להציג". המיקום הגיאוגרפי
  נבחר בפאנל ההגדרות (מספר ערים מוכנות מראש, קואורדינטות מותאמות אישית,
  או איתור אוטומטי דרך שירותי המיקום של Windows).
- **התראות:** שירות רקע (`ZmanimNotificationService`) בודק כל 30 שניות האם
  הגיע הזמן להתריע (לפי הזמנים ומספר הדקות-מראש שנבחרו בהגדרות), ומציג
  חלונית התראה שקופה קטנה שנעלמת אוטומטית.
- **תצוגת שולחן עבודה:** חלון שקוף נוסף, שקוף גם ללחיצות עכבר (Click-through),
  המציג את פרטי היום במיקום הנבחר (מרכז/פינה/מותאם אישית).
- **הגדרות:** נשמרות כ-JSON תחת `%AppData%\HebrewTaskbarWidget\settings.json`,
  ונכנסות לתוקף מיידית בכל חלקי האפליקציה ללא צורך בהפעלה מחדש.

## מגבלות ידועות

- **אין דרך נתמכת לפנות "מקום אמיתי" בתוך שורת המשימות עצמה.** שורת המשימות
  נשלטת לגמרי ע"י `explorer.exe`, ואפליקציה רגילה (כמו זו) אינה יכולה לגרום
  לה להזיז את סמלי המגש הקיימים ולפנות שטח - זו הסיבה שברירת המחדל היא
  "מעל שורת המשימות", שאינה חופפת לעולם.
- **הסתרת התאריך/שעה המקורית של Windows** פועלת ע"י הסתרה ישירה של חלון
  השעון (ראו CHANGELOG 0.5.1) - עובדת הן ב-Windows 10 והן ב-Windows 11, אך
  אם שורת המשימות עצמה מתאתחלת מחדש (קריסה/עדכון של Explorer) ייתכן הבהוב
  קצר של התצוגה המקורית עד לאכיפה החוזרת (תוך כשנייה וחצי).
- תמיכה בשורת המשימות **הראשית** בלבד (לא בצגים משניים עם שורת משימות נפרדת).
- לא נבדקה התנהגות מלאה במצב "הסתרה אוטומטית" של שורת המשימות (Auto-hide).
- הלוח העברי של .NET תומך בשנים לועזיות 1583–2239 בלבד.
- הזמנים ההלכתיים מוצגים לפי הכרעות נפוצות ומקובלות ולפי הלוחות, אך **אינם
  פוסקים הלכה למעשה** — לשימוש הלכתי בפועל יש להיוועץ ברב מוסמך.
- הנץ והשקיעה **הנראים** (מאחורי הרים) אינם מחושבים, כי הם דורשים מפה
  טופוגרפית. בשני הלוחות מוצג הנץ במישור; במישור החוף, למשל, הנץ הנראה
  שמודפס בלוח מאוחר ממנו בכמה דקות.
- הלוחות מחשבים שבירה אטמוספרית לכל עיר וחודש, ואור החיים מחשב מהנקודה
  הגבוהה בעיר, ולכן ייתכן הפרש של עד דקה מהלוח המודפס.
